# 走错的路

> 这个仓库里最重要的文件。
>
> 大多数开源项目只放成功的那一版，但读者真正想学的是「哪条路走不通」。
> 下面每一条都是**真的试过、真的失败过**，附当时的数字。

---

## 一、测量脚本骗了我整整两天

这是最贵的一个坑。**不是画不出来，是发现自己在用一把坏尺子，还量得特别认真。**

### 错误 1：`Image.transform` 参数写反

修之前的 MAE 是 **105**（0–255 尺度）。修完是 11 左右。

### 错误 2：参考图白底，渲染图深底

在深色页面上截图去和白底参考图比 —— MAE 虚高到 **147**。

### 错误 3：缩放导致的重采样误差混进几何误差

原来的做法是「页面 100% 宽、截图再缩回 743×1095」。
缩放本身引入的模糊被算进了「绘制误差」。

### 修完之后的口径

```
页面设成参考图的原生尺寸（743×1095），角色 1:1 铺满、不做任何缩放，
截完图直接逐像素比。
```

这样测到的误差只来自几何与着色，不含重采样损失。

**教训**：先验证尺子，再信数字。

## 二、逐层渐变着色 —— MAE 从 11.03 涨到 18.65

听起来完全合理：每层算一个光照方向，输出 `linear-gradient`。

实际跑出来 **MAE 从 11.03 涨到 18.65**。

推测原因（**推测，未单独验证**）：小色块内部本来颜色就均匀，
强行套渐变等于把「量化误差」换成了「渐变拟合误差」，而后者的
空间频率和参考图对不上。

**所以这个仓库不输出渐变。** 每个多边形就是一个纯色。

> 社区项目 [image-to-css-art](https://github.com/AvroraCL/image-to-css-art)
> 主打局部渐变拟合。两种都成立，但在这张图上我们量到的结果是变差。

## 三、把渲染密度提到 6 倍，误差几乎没动

超采样实验，DPR 1 / 2 / 3 / 4 / 6：

| DPR | MAE |
|---|---|
| 1× | 11.26 |
| 2× | 11.44 |
| 3× | 11.49 |
| 4× | 11.51 |
| 6× | 11.52 |

**从 1× 到 6×，误差只动了 2.2%。**

而三天的迭代把 MAE 从 19.36 压到 9.99（降 9.37）。

**结论（观测，不是推论）**：在这条管线上，加采样密度没有观察到改善。
剩下的差距在**边缘的表现方式**，不在采样精度。

⚠️ 这个结论只在 `clip-path` 这条管线上成立。换成 mask / filter /
`image-set()` 会不会不一样 —— **没测过**。

## 四、手绘 98 层，然后认输

第一版是老老实实照着参考图一层一层手画。

画到 98 层，判定「画不出 1:1」。差距不在层数，在曲线——
手画的贝塞尔曲线和原图的轮廓对不上，而且每一层都要重画。

后来改成自动轮廓追踪。**这一步是路线的转折，不是优化的胜利。**

## 五、孔洞的三种做法，只有一种划算

| 做法 | 结果 |
|---|---|
| 桥接（偶奇填充 + 算桥） | 能用，但桥要程序化生成，几百个嵌套环挨个算太费事 |
| 每个孔洞单独画一个反色块 | 层数爆炸 |
| **深度排序让更深的层盖住（采用）** | 层数变多，但不用算桥 |

painter's algorithm：按深度从小到大画，后画的盖住先画的。
洞就「自然形成」了——因为洞的位置上有更深的层。

## 六、残差层不是优化，是必需

第一遍量化跑完，嘴巴会消失。

原因：嘴巴不是一个细线，是一个**填充色块**，但面积太小，
K-means 拿不到独立色簇 —— 它被并进邻近的肤色里了。

局部中值法也检测不到它（它是实心块，不是边缘）。

解法是把「误差最大的那批像素」再聚类一次，作为更高深度的层追加：

```
第一遍量化 → 渲染 → 和参考图比 → 取误差最大的 N% 像素
  → 对这些像素再跑一次 K-means → 提轮廓 → 追加为更深一层
  → 重复
```

跑三轮。**嘴巴、眼高光、蕾丝孔洞、宝石反光，全是这一步捞回来的。**

这个方法有个特点值得记一下：**它会自动找回细节，不需要人工指定
「这里画嘴巴」。** 它直接最小化 MAE，所以哪里错得厉害就去补哪里。

## 七、K=72 那批数字是噪声

十二张缩略图，肉眼几乎看不出区别。但当时记下的数字说它们差了 **2.8 倍**，
而且不单调：

```
K=48 → 14.43
K=72 → 5.13    ← 突然变好
K=96 → 14.56   ← 又回去了
```

真实的参数效应不会长成这样。

那轮之后不再相信任何单个数字 —— **必须先让「量出来的」和
「看起来的」对得上**，否则量得越勤，错得越远。

## 八、其他

- **像素化的参考图放大会得到糊色块。** 原素材只有 143×198，
  所以后来用图生图重绘成 864×1152 的线稿再描。这一步不是放大，
  是「重新画了一遍」。
- **`_e_bl_*` 那批光晕素材完全对不齐**（MAE ~135 vs 参考 ~11），
  试过之后放弃。
- **不同混合比例的变体渲染出来像素级相同**（`_g_ik6_b0/b30/b50`，
  像素差 < 0.01），只有 b80 有区别而且更差（11.69 vs 11.36）。
  说明这几个参数在这个区间里饱和了。
